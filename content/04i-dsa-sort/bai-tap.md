# Sorting - Bài Tập

## Bài 1: Sort Colors (Dutch National Flag)
**Độ khó: Trung bình**

Cho mảng chỉ chứa 0, 1, 2. Sắp xếp in-place, chỉ 1 pass, không dùng sort.

**Đầu vào:** `nums = [2, 0, 2, 1, 1, 0]`
**Đầu ra:** `[0, 0, 1, 1, 2, 2]`

## Bài 5: Kth Largest Element
**Độ khó: Trung bình**

Tìm phần tử lớn thứ k. Yêu cầu: O(n) average.

**Đầu vào:** `nums = [3,2,3,1,2,4,5,5,6]`, `k = 4`
**Đầu ra:** `4`

**Gợi ý:** QuickSelect.
